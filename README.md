# Markdown Editor

Markdown Editor 是基于 Tauri + Rust + 原生 HTML/CSS/JavaScript 的本地轻量 Markdown 编辑器，正在按阶段执行冻结模型内核之外的模块化重写。

项目架构与长期记录见 [docs/README.md](docs/README.md)；当前阶段详录见 [R10-04](docs/R10-04-DETAILS.md)、[R10-05](docs/R10-05-DETAILS.md)、[R10-06](docs/R10-06-DETAILS.md)、[R10-07](docs/R10-07-DETAILS.md)、[R10-08](docs/R10-08-DETAILS.md)。
