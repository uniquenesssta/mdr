# Markdown Editor

Markdown Editor 是基于 Tauri + Rust + 原生 HTML/CSS/JavaScript 的本地轻量 Markdown 编辑器，正在按阶段执行除冻结模型内核外的模块化重写。

项目架构与长期记录见 [docs/README.md](docs/README.md)；当前阶段详录见 [R9-12](docs/R9-12-DETAILS.md)、[R10-01](docs/R10-01-DETAILS.md)、[R10-02](docs/R10-02-DETAILS.md)、[R10-03](docs/R10-03-DETAILS.md)。
