- 不迁移具体业务流程。

## 阶段 3：平台层重写

### 目标

拆除 `window.markdownEditorNative` 巨型接口。

### 工作

1. 建立 browser/desktop 平台端口。

- 无全局 native 对象。

## 12. 重点风险与禁止处理方式

- 统一端口变成巨型对象且无职责边界。
- 错误映射改变现有消息。
- 取消操作被记录为错误。
- 业务层继续直接 import Tauri。
- 旧全局对象仅改名未删除。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
