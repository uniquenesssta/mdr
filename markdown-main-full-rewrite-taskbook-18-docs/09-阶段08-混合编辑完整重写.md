## 12. 重点风险与禁止处理方式

- 组件目录拆了但共享一个巨型 index。
- 文档级监听器每组件重复注册。
- 异步 Mermaid 覆盖新状态。
- 直接编辑和源码编辑双状态。
- 复制表格解析规则。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
