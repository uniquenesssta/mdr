## 具体改变与理由

- 菜单按真实操作关系分组。文档操作、另存与导出、关闭分开；文字与图标形成稳定对齐列，快捷键靠右。恢复32px行高，宽度按内容确定，避免为了面积数字好看而压缩。
- 表单使用统一的标题、内容、操作三区。标题16/24 Medium；内容左右20px；底部56px操作区有浅底色和完整轮廓。字段标签与字段靠近，错误说明随内容增长。
- 导出格式、图片来源、图片比例使用同一分段选择结构。只有当前选择有白色底，蓝色实心按钮保留给最终动作。
- 输入框默认使用较轻的边界，焦点与错误保留明确强调。多行源码字段统一圆角和边线，原有输入、滚动与校验职责保留。
- 格式工具条按功能分组；“更多”仍直达工具条设置，不恢复长列表。调色板减少每个色块的重复边框。
- 浮层统一轮廓和柔和阴影，区分正文、浮层与最终动作；保留用户要求的细分隔线。已同步浅深主题和桌面／窄短窗口实例。

这次使用了已授权的 Impeccable Operate、craft-floor、new-work 中的局部扩展原则，以及 Figma 组件／页面技能。Impeccable 二进制检测器仍未运行，不用它作为通过依据。学习参考：[Fluent 菜单分组与快捷键](https://fluent2.microsoft.design/components/web/react/core/menu/usage)、[Fluent 弹窗类型和内容结构](https://fluent2.microsoft.design/components/web/react/core/dialog/usage)。没有安装新技能、引入 UI 框架或照搬其他产品业务。
