## 实现与安全边界

`html-to-markdown.js` 唯一负责 DOM→Markdown 与元信息组合。支持标题、段落、粗斜体/删除线、链接、图片、行内与围栏代码、嵌套列表、引用、分隔线、表格。同步纯转换无网络、DOM 写入、监听或异步代次状态；无效根节点抛 TypeError。代码内容保持换行及空行，围栏长度超过内容最长反引号串；表格补齐列数并转义管道符；有序列表读取 start。仅在首个 H1 与元信息标题完全匹配时去重，修复旧前缀误删。

原文本及标题/作者/日期作为字面文字转义，避免源网页文字再次成为 HTML/Markdown 指令。转换仅输出支持的结构，不输出脚本、嵌入节点或事件属性。链接和图片 URL 复用既有 `document-html.js` 的同一判定函数（只导出并重命名，不修改允许策略），再对 Markdown 目的地址的分隔字符编码；被拒绝的链接退化为文字、图片退化为 alt。允许的图片相对路径与 raster data URI 保留；百分号编码的冒号作为相对路径，不解码为协议。未建立第二套净化策略。

转换器具备图片规则，并有正常图片夹具及渲染回归；13.10 提取器保持已验收的去图片策略，所以当前网页剪藏 UI 仍不导入网页图片。本项不擅自改变外部资源产品策略。HTML sink 净化始终保留，不能以输入转换替代 Preview/Hybrid 的独立防护。

组合根挂载受限转换端口，旧 UI 调用 extract→convert→已有文档插入。旧 htmlToMarkdown、convertTable 及元信息 Markdown 拼接全部删除。转换端口在 pagehide/启动失败销毁，旧句柄拒绝使用，重复销毁安全且不覆盖后继所有者。抓取取消与过期隔离仍由13.9负责；没有为同步转换引入无意义取消状态。

## 验证与兼容变化

固定 JSON 夹具对比覆盖正常格式、嵌套/有序列表、链接地址括号、图片 alt、raw HTML/Markdown 字面文本、动态代码围栏与空行、行内代码、引用换行、表格短行、脚本剔除与空输入。另测元信息注入、完整标题去重及前缀不误删。
