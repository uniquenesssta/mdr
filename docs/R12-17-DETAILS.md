## 实施与兼容性

将 `external_link.rs`、`web_fetch.rs`、`performance_log.rs` 迁入对应目录的 `mod.rs`，各新增一个 `command.rs` 作为现有 Tauri 命令的唯一所有者。外链命令负责校验后系统打开；网页命令负责校验、客户端、响应和计时编排；日志命令负责批次参数与 Writer 返回路径投影。没有纯转发函数、第二份实现、新状态或新依赖。

`main.rs` 只更改三条模块路径。全部 19 个注册命令的名称、顺序和数量保持不变；另外 16 条路径、插件、DocumentStore 管理和启动/退出顺序不变。前端 payload、DTO、协议规则、网络超时和重定向、日志策略及错误传播均保持。日志模块保留原后端计时职责，未为了目录形式增加额外拆分。

现有 Rust 行为测试继续调用真实命令：模块入口只在 `cfg(test)` 下导入命令供旧测试使用，不提供生产兼容入口。外链拒绝、真实 HTTP 成功/失败/超时、日志真实 I/O 失败与恢复、锁中毒和 release 不落盘继续验证。命令不新增资源、后台任务或取消令牌；已有 HTTP 客户端和 Future 的作用域清理语义保持，不虚构单独销毁对象或新增取消协议。
