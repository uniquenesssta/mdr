## 实现与职责

控制器唯一持有 URL/代理/手动输入、抓取源 HTML 和剪藏会话代次；状态快照不暴露抓取 HTML，只暴露 hasContent。打开、关闭、修改任一输入、新请求、插入与销毁均取消抓取并作废旧结果。返回时同时验证控制器会话和抓取协调器代次。手动转换抢先取消在途请求；成功插入关闭会话，重复按钮事件不重复插入。转换异常保留源以供重试。

界面负责控件、状态文字和模态框事件，错误及代理提示使用 textContent；所有按钮/输入事件通过可移除监听绑定，不保留 source 状态。保持默认代理地址与桌面路径、翻译、空内容提示、手动回退和模态框焦点。模态框 onClose（含 shell ESC/背景关闭）回调清空控制器会话；销毁解绑所有监听、关闭活动框并销毁控制器。

组合根注入已验收抓取协调器、提取器、转换器及平台能力。新受限端口仅负责一次激活、打开和视图释放；旧三个抓取/提取/转换端口不再挂载，历史模块及其独立测试留给13.14清除。经典脚本仅保留文档插入/Preview更新/保存回调、菜单打开委托、Find同步及通用Toast；其文档接口在13.13联调整理。core 中 fetchedHtml 全局状态和旧剪藏按钮函数全部删除；性能封装名单移除不存在的 convertAndInsert，避免悬空入口。

未修改抓取安全策略、HTML净化规则、模型算法、持久化和正常插入位置语义。不会提前声称13.13全链路或A05关闭。
