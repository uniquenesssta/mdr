# R11-13 — Upload Session (Upload ID, Temp File, Append/Commit/Abort, Cleanup)

- 基线与前置：本 Atomic 建立在本地 R11-12 Chunk Reader 改动之上。沿用用户在本轮明确指示的方针——不再以真实 CI 结果作为开始各 Atomic 的前置条件，仅依赖本地验证结果推进。
- 任务书依据：执行 Stage 11 Atomic 11.13 Upload Session。目标是把上传 ID、临时文件、append/commit（经 take）/abort 和清理从 `repository.rs` 提取到独立文件；必须产出并发会话隔离的测试证据。
- Upload Session 边界：新增 `src-tauri/src/document_store/chunks/upload_session.rs`，拥有 `begin_snapshot_upload`/`append_snapshot_chunk`/`take_snapshot_upload`/`abort_snapshot_upload` 四个函数——原样迁移自 `repository.rs` 同名函数，函数体、错误文案（“无法创建/打开/写入/读取/清理分段快照：{err}”）逐字保留。四者仍依赖 `paths::snapshot_upload_path` 构造临时文件路径——该函数本身是纯文件名构造逻辑，继续留在 `paths.rs`（R11-03 已确立的边界），未被本次迁移触及。不涉及文档保存/加载编排或快照写入——那些留在 store 编排层与 `snapshot`。
- 并发隔离依据：每个会话完全由调用方传入的 `upload_id` 经 `snapshot_upload_path` 映射到独立的 `snapshot-upload-{id}.tmp` 临时文件寻址，四个函数内部不持有任何跨会话共享状态（无内存哈希表、无全局计数器），因此不同 `upload_id` 的并发会话天然通过文件系统路径隔离，互不可见、互不干扰。
- 编排保持：`document_store.rs` 的四个 Tauri command（`begin_document_snapshot_upload`/`append_document_snapshot_chunk`/`commit_document_snapshot_upload`/`abort_document_snapshot_upload`）未改变签名或调用方式，仅调用来源从 `repository::{...}` 改为 `chunks::{...}`。
- 导入清理：`repository.rs` 顶部模块文档更新为仅描述 `write_atomic`/`ensure_dir` 这两个仍留在这里的通用原子文件 IO 原语；`use super::paths::snapshot_upload_path;` 与 `std::fs::OpenOptions` 随四个函数一并移除（`OpenOptions` 在 `repository.rs` 内此前唯一的消费者就是 `append_snapshot_chunk`）。`document_store.rs` 的 `use repository::{...}` 收窄为仅 `ensure_dir`，四个上传会话函数改由 `use chunks::{abort_snapshot_upload, append_snapshot_chunk, begin_snapshot_upload, read_chunk, take_snapshot_upload};` 引入。
- 测试迁移：`repository.rs` 原有的 4 项上传会话测试（往返读写、缺失文件报错、幂等 abort、abort 清理临时文件）随函数一并迁移到 `chunks/upload_session.rs`，未在原位置保留重复断言；`repository.rs` 自身保留的 `ensure_dir_creates_nested_missing_directories`、`write_atomic_creates_new_file_and_overwrites_existing_target_without_leaving_temp` 两项测试不变。
- 兼容夹具：`document_store_compatibility.rs` 无需改动——`repository.rs` 不在其冻结 token 扫描范围内，本次迁移未涉及任何冻结 token。
- 新契约测试：`chunks/upload_session.rs` 除迁移来的 4 项测试外，新增 1 项 `concurrent_sessions_with_different_upload_ids_never_share_or_touch_each_others_file`——同时开启 `session_a`/`session_b` 两个会话、分别追加不同内容、中途 abort 其中一个，验证被 abort 的会话临时文件消失且不影响另一个会话的临时文件与已追加内容，直接对应任务书要求的“并发会话隔离”交付物。共 5 项测试。`document_store.rs` 原有的端到端集成测试（`saves_million_character_snapshot_from_chunks`，覆盖 begin/append/take 全链路 + 保存）保持不动、继续通过。
- 受保护范围：未修改 `src-tauri/src/main.rs`、`Cargo.toml`、`Cargo.lock`、`document_store/{validation,paths,types}.rs`、`document_store/snapshot/*`、`document_store/journal/*`、`document_store/index/*`、`document_store/chunks/reader.rs`、任何生产依赖、Tauri command 名称、DTO、磁盘布局、临时文件命名规则（`snapshot-upload-{id}.tmp`）。无新增生产依赖。
