## 12. 重点风险与禁止处理方式

- 遥测成为新的全局 service。
- 敏感内容在聚合前泄漏。
- E2E API 暴露生产能力。
- 测试继续按源码字符串断言。
- 计时器/observer 泄漏。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
