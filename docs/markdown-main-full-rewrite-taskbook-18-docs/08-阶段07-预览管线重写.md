## 12. 重点风险与禁止处理方式

- 主线程再次全文复制。
- Worker 响应缺少版本令牌。
- 虚拟化和渲染共享可变数组。
- 布局 Observer 触发无限重渲染。
- 失败路径同步全文 fallback。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
