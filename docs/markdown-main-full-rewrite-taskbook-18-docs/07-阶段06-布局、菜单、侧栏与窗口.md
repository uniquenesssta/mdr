## 12. 重点风险与禁止处理方式

- 布局模块触发预览渲染。
- 菜单项直接 import feature 内部。
- 侧栏拥有文档列表状态。
- resize 监听泄漏。
- 紧凑模式和普通模式双重修改 DOM。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
