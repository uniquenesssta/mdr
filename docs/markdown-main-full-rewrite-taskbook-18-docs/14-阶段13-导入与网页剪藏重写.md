## 12. 重点风险与禁止处理方式

- 拖放控制器继续承担解析。
- 失败创建空文档。
- HTML 转换规则改变内容。
- 浏览器和桌面结果不一致。
- 大图片警告丢失。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
