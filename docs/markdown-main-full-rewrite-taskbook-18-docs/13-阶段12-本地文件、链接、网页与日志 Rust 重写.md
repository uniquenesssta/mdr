## 12. 重点风险与禁止处理方式

- 路径安全被拆散后出现绕过。
- 重定向绕过 URL 校验。
- 日志脱敏只处理顶层。
- 文件树递归无界。
- 命令改名或参数字段变化。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
