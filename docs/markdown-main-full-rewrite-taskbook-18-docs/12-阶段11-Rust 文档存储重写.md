## 12. 重点风险与禁止处理方式

- 看似重构但序列化字段顺序/缺省变化。
- Mutex 作用域扩大。
- 恢复逻辑分散。
- 临时上传文件泄漏。
- 错误字符串变化破坏前端。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
