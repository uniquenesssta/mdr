## 12. 重点风险与禁止处理方式

- 翻译键拆分时丢失占位符。
- 设置 UI 直接修改运行状态。
- 非法旧值被自动覆盖。
- 帮助内容继续膨胀 locale 文件。
- 主题文件复制所有组件规则。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
