## 12. 重点风险与禁止处理方式

- 多个保存入口并发写入。
- 保存状态由 DOM class 反推。
- 分块上传代理对被拆断。
- 关闭失败仍退出。
- 浏览器和 native 同时保存全文。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
