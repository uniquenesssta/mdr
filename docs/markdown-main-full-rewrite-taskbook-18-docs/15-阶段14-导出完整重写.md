## 12. 重点风险与禁止处理方式

- 导出和自动保存继续耦合。
- PDF 后预览不恢复。
- HTML/Word 模板重复。
- 取消后任务继续提交 UI。
- 图片资源失败导致整任务挂死。

禁止用以下方式“解决”风险：

- 增加永久白名单
- 保留旧实现作为 fallback
- 捕获异常后静默忽略
- 用 mock 代替必须验证的真实调用链
- 降低测试断言或删除失败场景
- 通过 service locator、全局单例或通用 helpers 转移耦合
