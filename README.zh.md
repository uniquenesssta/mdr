# Markdown Editor

Markdown Editor 是基于 **Tauri + Rust 后端 + 原生 HTML/CSS/JavaScript 前端** 重构的本地轻量 Markdown 编辑器。

本版本不再以单个 `markdown-editor.html` 作为应用入口，而是采用桌面应用结构：

```text
index.html                  # 前端入口
src/                        # 前端源码
  main.js
  document/
    document-model.js       # 统一文档版本、事务日志与显式全文快照
  editor/
    virtual-editor.js        # CodeMirror 6 虚拟编辑器与旧接口兼容层
  preview/
    incremental-preview.js   # Markdown 变更窗口与增量块模型
    preview-worker.js        # 后台 Markdown 解析线程
    preview-worker-client.js # 版本化变更事务与过时请求合并
    virtual-preview.js       # 超大文档预览窗口化与高度索引
    enhancement-queue.js     # 数学公式与 Mermaid 的版本化可取消队列
  storage/
    native-document-store.js # CodeMirror 变更事务与 Rust 后台存储协调
  runtime/
    vendor.js               # marked / KaTeX / Mermaid / dom-to-image-more 注入
    tauri.js                # Tauri Rust 后端桥接
    performance.js          # 前端操作与渲染性能采集
  styles/
    index.css               # 单一有序样式入口
    foundation/             # reset、令牌、排版、可访问性与动效
    themes/                 # 亮暗主题视觉令牌
    shell/                  # App Shell 视觉结构
    layout/                 # 侧栏、分栏、紧凑与全屏布局
    components/             # 通用视觉组件
    features/               # 编辑器、预览、导出及混合编辑样式
public/
  i18n.js                   # 多语言文本
  app/                      # 前端功能模块（按职责拆分）
    core.js                 # 状态、文档、侧栏、设置与布局
    scroll-sync.js          # 双向滚动与划词定位
    bootstrap.js            # 初始化与状态恢复
    preview.js              # Markdown 预览渲染
    export.js               # 保存、导入与导出
    editor-tools.js         # 过渡：布局/全屏、可视编辑开关与 Mermaid 预览增强（后续阶段拆除）
    web-clipper.js          # 网页抓取与 HTML 转 Markdown
    events.js               # 全局事件、拖放与快捷键
src-tauri/                  # Tauri / Rust 桌面后端
  src/main.rs
  src/document_store.rs     # 超大文档增量日志与双槽快照
  src/web_fetch.rs
  src/performance_log.rs    # 性能日志落盘
logs/                       # 开发者性能日志目录
```

## 功能

- CodeMirror 6 可视区虚拟编辑与实时预览
- 可选单视图混合编辑：当前块显示 Markdown 源码，其余可见块隐藏标记并呈现排版效果
- 顶部应用菜单栏：文件、编辑、视图、插入、应用
- Typora 风格左侧栏：本地文档切换、大纲标题跳转
- 设置面板：主题、语言、默认布局、侧边栏显示状态、自动保存预设或自定义秒数、超大文档预览策略
- 左侧源码编辑 / 右侧实时预览
- 多主题
- 多语言
- 本地导入与拖拽导入
- Markdown / HTML / Word / PDF / 图片导出；桌面端“另存为 Markdown”使用系统文件选择器，可选择保存位置
- KaTeX 数学公式
- Mermaid 图表
- 从网页导入 Markdown
- 桌面版通过 Rust 后端抓取网页，不依赖 Python 代理

## 开发者性能日志

应用会把前端交互、预览渲染、滚动与划词同步、文档操作、导入导出、Rust 命令、长任务、异常和定期运行状态写入根目录：

```text
logs/performance-YYYY-MM-DD.jsonl
```

日志采用 JSON Lines 格式，一行代表一次操作或一组高频操作的聚合结果。高频滚动、输入和同步事件按时间窗口聚合，字段包含调用次数、平均耗时、最小耗时和最大耗时，避免日志采集本身影响编辑流畅度。日志不会记录 Markdown 正文、网页内容或本地文件完整路径。

性能日志仅在开发模式启用，并固定写入项目根目录 `logs/`。正式发布版本不启动性能采集、不创建 `logs/` 目录，也不会写入性能日志。开发模式下可通过环境变量 `MARKDOWN_EDITOR_LOG_DIR` 指定日志目录。

## 大文档性能策略

- 单视图混合编辑复用同一个 CodeMirror 文档状态，不维护第二套富文本编辑器；当前光标块和选区始终显示原始 Markdown，其他可见块仅通过视口装饰呈现标题、引用、列表、强调、链接和代码样式。
- 单视图模式暂停独立预览 DOM 提交，但 Preview Worker 继续维护标题、统计和块索引；切回双栏时根据已有 Worker 模型恢复虚拟或完整预览。
- 混合呈现只处理 CodeMirror 当前可见行，百万字符文档的装饰计算不会遍历全文；输入法、撤销、保存和查找仍使用原编辑器事务链路。
- 编辑区使用 CodeMirror 6 可视区渲染；DOM 只保留当前视口附近的行，完整文档保存在编辑器状态树中。
- 新增统一 `DocumentModel`：编辑器、预览 Worker、查找替换和 Rust 后台保存共享同一文档代次、版本号和变更事务，不再各自维护独立的增量状态。
- `DocumentModel` 为预览与存储维护消费者确认位置；已被所有消费者确认的事务会回收，未同步消费者超出日志窗口时才显式回退为一次完整快照。
- 全文字符串改为显式快照操作并记录用途；普通格式化、选区同步、查找和局部替换只读取所需区间，避免百万字正文被隐式复制。
- 编辑器保留现有 `value`、选区、替换和滚动接口，工具栏、快捷键、文档存储与双向定位无需改写。
- 预览维护顶层 Markdown 块模型，普通编辑只重新词法分析变更窗口；未变化的段落、标题、列表、公式和图表节点直接复用。
- 增量块比较使用线性索引，避免超大文档全量更新时出现随块数量平方增长的比较开销。
- 10 万字符以上的 Markdown 分块与增量解析转移到 Web Worker；主线程只接收变化块和源码范围，连续输入期间只保留最新待处理请求。
- Worker 根据当前光标所在标题章节优先生成最多 96 个块、约 12 万字符的 HTML；光标跨章节后只刷新新的优先窗口，避免主线程重复解析当前写作区域。
- 超大文档中的 Markdown 引用定义仍在 Worker 中做全局语义分析，但不再要求主线程生成整篇预览 DOM；定义变化只失效已有块缓存并更新当前虚拟窗口。
- 数学公式和 Mermaid 进入版本化空闲任务队列；新预览版本会取消尚未开始的旧任务，当前章节和可见块优先处理。
- 虚拟预览会根据滚动方向让 Worker 低优先级预热视口前后的最多 96 个块；进入新区域时优先复用已生成 HTML，减少主线程临时 Markdown 解析。
- 公式和 Mermaid 队列按“真实可见区、当前章节、缓冲区”三级调度，动效和重型增强不会抢占当前阅读区域。
- 超过 40 万字符或约 1400 个预览块时启用真正的预览窗口化；DOM 只挂载视口前后 24–180 个富文本块，其余区域由块高度索引和上下占位维持滚动长度。
- 预览策略支持“自动、全文虚拟、仅当前章节、完整预览”四种模式；自动模式会按字符数和块数分级，百万字符级文档默认优先当前章节，用户仍可在设置中手动覆盖。
- “仅当前章节”模式使用 Worker 已生成的章节块快照，不创建全文预览 DOM；光标跨章节后才切换预览范围，并保留章节内的增量更新和可见节点动效。
- 虚拟预览的图片、公式和 Mermaid 仅在块进入可见窗口后增强；异步高度变化由 ResizeObserver 校准，动效仍只作用于本次变更的可见节点。
- 预览锚点建立缓存并使用二分查找；编辑器和预览滚动事件按动画帧合并，避免每个原始滚动事件遍历全部块。
- 侧边栏、分栏、菜单、模态框、预览高亮和增量块进入动效继续保留；预览块动效仅作用于本次变更节点。
- 分栏、侧边栏和窗口尺寸连续变化时，行索引在布局稳定后重建一次。
- 增量块模型直接维护源码行号和字符区间，普通输入不再为预览定位重复解析整份 Markdown；双向滚动改用虚拟块高度索引定位离屏内容。
- 字数统计由编辑事务增量维护，输入时不再重复扫描整份百万字文本。
- 撤销/重做使用 CodeMirror 事务历史，不再每 400 毫秒复制并保存一份完整大文档快照。
- Worker 已同步后，普通预览刷新只提交编辑事务；主线程不再为每次预览更新构造完整文档字符串。
- 查找使用 CodeMirror 分块文本接口扫描，不再为每次“查找下一个”复制整篇文档；全部替换会合并为一次编辑事务，避免百万字文本被反复切片和拼接。
- Worker 异常时，超大文档不会回退到主线程全文渲染；界面会保留最后一次稳定预览或显示轻量恢复提示，防止故障路径再次冻结窗口。
- Tauri 中达到 10 万字符的文档会迁移到 Rust 后台存储：首次写入完整快照，后续自动保存只提交 CodeMirror 变更事务。
- Rust 后端把事务追加到增量日志，并在 24 次写入、日志达到 2 MB 或手动保存时压缩为双槽校验快照；旧槽保持可恢复状态，降低保存中断造成损坏的风险。
- 启动加载会校验双槽快照与增量日志的版本连续性、UTF-8 和事务范围；若日志尾部因异常退出而截断，会保留已验证前缀、重建安全快照并向用户提示恢复结果。
- 当前快照损坏时会自动尝试备用槽；只有两个槽都无法通过完整性校验时才停止加载，避免静默返回错误正文。
- 状态栏会显示自动保存的等待、后台写入、快照完成和失败状态；相同版本且标题未变化的重复保存会直接跳过，不再产生空增量日志。
- Word、HTML、PDF 和图片导出会按块分批构建完整内容并显示进度；解析、增强和图片准备阶段可取消，PNG 最终编码阶段会明确进入不可立即取消状态。
- 快照始终写入非当前槽位；窗口关闭前会等待最后一批事务落盘并压缩快照，保存失败时阻止直接退出，避免自动保存间隔内的修改丢失。
- 本地存储只保留已迁移大文档的标题、时间和版本元数据，避免每次自动保存都在界面线程序列化百万字正文；浏览器预览模式继续使用原本的 localStorage 兼容路径。
- 大文档连续输入会合并为一次短延迟预览刷新；超过 40 万字符时会采用更长的空闲等待，编辑器输入本身保持即时响应。
- 大纲只有结构实际变化时才重建 DOM；普通正文编辑只更新当前标题状态。
- 预览源码锚点优先建立，大纲和选择增强放到空闲阶段执行；首次滚动前会预热锚点坐标。
- 后台预热、预览后处理、重型增强、索引缓存和高度缓存统一进入可取消的优先级调度器；新的同类任务会取消旧任务，输入与可见区更新始终优先。
- Worker 直接维护增量标题索引和文档统计；主线程不再为每次预览更新遍历全部 Markdown 块，大纲索引会按文档指纹持久化并在启动时提前恢复。
- 启动已有文档时不再先加载旧版全文再覆盖当前文档；窗口先完成首帧绘制，再恢复正文、索引和预览，避免百万字文档重复构建 CodeMirror 状态。
- Rust 后台会先返回文档清单、字符数、行数和标题索引，再按约 512 KB 分段把正文传给前端；CodeMirror 直接从分段文本构造状态，不再要求界面线程先拼接一份百万字字符串。
- 首次预览 Worker 可直接复用分段恢复数据，避免文档刚打开时在主线程调用完整 `toString()`；Worker 同步完成后释放启动分段缓存。
- 40 万字符以上且已迁移到原生存储的文档使用 Rust 后台“查找下一个”；搜索前只提交最新编辑事务，中文与 Emoji 位置通过稀疏 UTF-16 索引映射，界面线程不扫描整篇正文。
- 原生标题索引在正文传输前即可恢复大纲；分段读取显示进度，新的文档打开请求会取消尚未完成的旧读取任务。
- 虚拟预览会按文档、主题、字号和宽度分桶持久化已测量块高度；再次打开相同文档时优先恢复高度索引，减少滚动条长度修正和首轮定位跳动。
- “全部替换”改为按 64 KB 文本块扫描匹配并一次提交事务，不再为了查找匹配位置先复制完整文档字符串。

## 开发运行

需要安装：

- Node.js
- Rust
- 系统 WebView 运行依赖

安装前端依赖：

```bash
npm install
```

前端依赖包含 CodeMirror 6（`@codemirror/state`、`@codemirror/view`、`@codemirror/language`、`@codemirror/lang-markdown`、`@codemirror/commands`、`@lezer/markdown`），以及 Tauri 文件对话框和文件写入插件（`@tauri-apps/plugin-dialog`、`@tauri-apps/plugin-fs`）。新增插件不要求升级 Node.js、Rust、Tauri 主版本或系统 WebView，但覆盖项目后必须重新安装依赖并重新编译 Tauri。

启动 Tauri 桌面开发模式：

```bash
npm run tauri:dev
```

使用 pnpm 时：

```bash
pnpm install
pnpm tauri dev
```

项目已在 `pnpm-workspace.yaml` 中仅允许 `esbuild` 执行必要的安装脚本，兼容 pnpm 11 的依赖构建安全策略，无需再手动运行 `pnpm approve-builds`。

仅启动前端预览：

```bash
npm run dev
```

## 构建桌面应用

```bash
npm run tauri:build
```

或：

```bash
pnpm tauri build
```

构建产物位于：

```text
src-tauri/target/release/bundle/
```

Windows 构建生成 NSIS 安装程序。安装向导支持自定义安装目录；使用相同应用标识安装时会覆盖升级现有版本，并注册 `.md` / `.markdown` 文件关联。双击关联文件会直接在编辑器中打开。

## 说明

桌面版网页抓取由 `src-tauri/src/web_fetch.rs` 提供。浏览器预览模式下仍可使用公共 CORS fallback 或手动粘贴 HTML。

左侧“文档”基于本地存储保存和切换 Markdown 文档；左侧“大纲”根据当前 Markdown 标题实时生成，点击后跳转到对应源码行。

## 滚动同步控制器

编辑器与预览的双向滚动由 `src/sync/scroll-controller.js` 独立管理。只有滚轮、触摸、滚动条拖动或滚动按键可以取得滚动源所有权；联动滚动、定位滚动和虚拟预览高度补偿不会反向触发同步。虚拟预览通过块高度索引直接完成源码行与预览位置映射，并在块高度变化后由控制器从当前用户源侧重新校准。

## 选区同步控制器

编辑器与预览的划词同步由 `src/sync/selection-controller.js` 独立管理。控制器会等待 WebView 最终提交选区、阻止编辑器与预览相互反馈、挂载选区所需的虚拟预览范围，并在虚拟节点被替换后自动恢复高亮。预览到源码的映射优先使用当前块和 DOM 相对位置，回退搜索只检查相邻 64 KB，不再为划词复制整篇超大文档。
